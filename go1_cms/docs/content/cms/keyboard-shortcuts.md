# Keyboard shortcuts

Press **?** in the builder to show this list. On Windows and Linux, use Ctrl where it says ⌘ and Alt where it says ⌥.

## Editing

| Shortcut | Action |
| --- | --- |
| ⌘S | Save now |
| ⌘Z | Undo |
| ⌘⇧Z or ⌘Y | Redo |
| Esc | Clear the selection |
| ⌘C / ⌘V | Copy and paste (works across pages and websites) |
| ⌘D | Duplicate |
| Delete or Backspace | Delete |
| ⌘⌥C / ⌘⌥V | Copy and paste style |
| ⌘⇧V | Paste from Figma |

## Selection and arrangement

| Shortcut | Action |
| --- | --- |
| Shift + click | Add to or remove from the selection |
| Drag from empty space | Box-select inside a section |
| Shift + drag | Box-select from anywhere |
| ⌘G / ⌘⇧G | Group / ungroup |
| Arrow keys | Nudge 1px |
| Shift + arrow | Nudge 10px |
| ⌘↑ / ⌘↓ | Move earlier / later among siblings |
| ⌥A / ⌥H / ⌥D | Align left / centre / right |
| ⌥W / ⌥V / ⌥S | Align top / middle / bottom |
| ⌥ + drag a handle | Resize without snapping |

## View

| Shortcut | Action |
| --- | --- |
| ⌘+ / ⌘− | Zoom in / out |
| ⌘0 | Fit to screen |
| ⌘1 | Actual size |
| ⇧2 | Zoom to the selection |
| Space + drag | Pan the canvas |

## Admin

In the admin, ⌘1 to ⌘9 open the main screens and ⌘K opens the command menu. In the docs editor, ⌘S saves and ⌘⇧P publishes.
