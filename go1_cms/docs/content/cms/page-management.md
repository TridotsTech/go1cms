# Managing pages

The **Projects** screen holds every website as a folder of pages, each shown as a live thumbnail. Hover a card to tour the page.

## Finding pages

Search by name, filter by Draft or Live and by tag, sort by date, and switch between grid and list. The open project is kept in the address, so back and refresh return to it.

## Creating pages

- **Blank**, from an existing design in the project, from a saved section, from a **page template**, or generated with AI.
- **Page templates**: save any page as a template from its card, then start new pages from it in any website. A template is a copy: changing it later does not touch pages already made from it.

## Organising

- **Folders** in the builder's Pages tab are shared by the whole team.
- **Parent pages** build the page tree. A password on a parent page can cover its child pages.
- **Tags** group pages across folders.
- **Move** a page to another project.

## Bulk actions

Select several pages to publish, unpublish, move, tag or delete them at once. Every action checks your access to each page.

## Password-protected pages

Lock a page behind a password, optionally covering every page under it, so a whole part of a website sits behind one password. The page's content is never sent to a visitor who has not unlocked it.

## Recycle bin

Deleting a page moves it to the bin with its history for 30 days. **Restore** brings it back under the same address as a draft, so it never goes live on its own. Pages older than 30 days in the bin are deleted for good.

## History

Every publish is recorded with the page, who and when. The publish screen lists them, and keeps edits made since the last publish apart. A version replaced by "keep mine" in a save conflict, or changed by AI, is kept as a revision you can go back to.
