# Create a website

A website is a **project**: a set of pages, menus, a theme, collections and settings that publish together to one address.

## From the control panel

Press **Create website** on the control panel. You choose:

- **Website name**, shown in the builder and used to seed the address.
- **Web address**, a label under `go1cms.site`. Lowercase letters, digits and hyphens, three to 63 characters. Reserved words such as `www`, `api` or `admin` are refused, and the check runs as you type.
- **Plan**, when you have more than one available. A plan change from here starts a 14-day trial.

## What each plan creates

| Plan | What is created | Ready in |
| --- | --- | --- |
| Starter | A project on a shared GO1CMS site | seconds |
| Medium | A site of your own on our shared server | a few minutes |
| Premium | A site of your own on a dedicated server | after the server is ordered |

The control panel shows the website as **provisioning** until it is ready, then **active**. **Open builder** signs you in and opens it.

## Inside a website

A Medium or Premium site can hold several projects, each with its own address and domain, up to your plan's **websites** limit. Create them from the Pages screen with the project switcher. On Starter the one project is your website.

## Renaming and deleting

Rename a project from its settings. Deleting a website archives it in the control panel and unpublishes its pages. Its address becomes available again after a short delay.
