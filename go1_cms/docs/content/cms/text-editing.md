# Editing text

Double-click any text or heading to type into it in place.

## The text toolbar

While you edit, a toolbar floats above the text and follows it as you scroll. It switches between paragraph and H1 to H3, applies bold, italic and strikethrough, adds or removes a link, and sets the colour of the selected words.

## Headings and structure

A heading element keeps its level (H1 to H6) separately from its size. Change the size in Typography without changing the level, so search engines and screen readers still read the page outline correctly. Use one H1 per page.

## Links

A link can point at another page of the website, a section on the same page, an email address, a phone number or any URL. The link picker lists the website's pages, so you do not have to type addresses.

## Pasting

- Text pasted into a text element keeps only simple formatting.
- HTML pasted onto the canvas becomes builder elements, and pasted CSS becomes styles on the selection.
- An image on the clipboard is uploaded to the media library and inserted.
- ⌘⇧V pastes a Figma selection (see [Figma and imports](../figma-and-imports)).

## Rich text

The **Rich Text** element holds long, formatted copy such as terms or a policy, with lists, quotes and links, edited in a document-style editor.

## Rewriting with AI

Select text and use the AI panel to shorten it or change its tone, or rewrite the whole page's copy at once (see [AI copywriting](../ai-copy-and-images)).
