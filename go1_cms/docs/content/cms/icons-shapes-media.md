# Icons, shapes and media

## Icons

The icon picker searches several icon sets at once, including Lucide, Tabler, Feather and Bootstrap icons. After placing an icon you can change its size, stroke, colour and background in the icon customiser. A menu item can use an icon too.

## Shapes and decorations

The **Shapes** group in the Elements panel has lines, basic shapes, stars and badges, arrows, callouts and banners, organic blobs, flowchart shapes, symbols and outlines. Shapes are vectors: they stay sharp at any size and take theme colours.

**Section dividers** add a wave, slant or curve at the top or bottom of a section.

## Mockups

Device and product mockups place a screenshot inside a smartphone, a computer, a video frame, printed matter, apparel, packaging, home and living or outdoor scenes.

## Images

- Pick images from the [media library](../media-library), upload new ones, or search stock photos.
- Every image has alt text. The library's alt text is used wherever the image appears unless you set a different one on the page.
- Set a **focal point** so the important part stays visible when the image is cropped at different sizes.
- Images are served in web sizes automatically (see [Speed and caching](../performance)).

## Video

The **Video** element plays an uploaded video or a video file URL; use an embed for YouTube or Vimeo. A section can have a background video. Uploaded videos get a poster frame and a web-friendly copy when the server has ffmpeg installed.

## Embeds

The **HTML Embed**, **Map**, **Social Embed** and **Audio Player** elements bring in third-party content. Embeds run only on the published page, not inside the builder.
