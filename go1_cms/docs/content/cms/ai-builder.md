# AI builder

Describe the site, get a first draft.

## From a brief

**AI builder** asks for the business, the audience and the tone, then generates pages section by section. Sections stream onto a board as they are produced; you can redo any one, add a page or regenerate images. Everything it makes is ordinary editable elements.

## In the builder

The **AI** panel rewrites selected copy, generates a section from a prompt, or suggests alt text for images.

## Bring your own key

Set the provider and key under **AI settings**. Generation runs as background jobs, so a long site does not block the browser.
