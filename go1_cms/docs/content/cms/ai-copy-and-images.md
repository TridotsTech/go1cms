# AI copywriting, section redo and images

## Rewrite a page's copy

The **copywriter** rewrites every heading, paragraph and button label on a page for a tone, a length and an audience you choose, and keeps the layout exactly as it is. Text goes to the AI in batches and a rewrite is only used when it comes back complete, so a page is never left half-written.

## Brand voice

Save the website's voice once in **Theme Studio › Brand**: tone, audience, words to use, words to avoid, and notes. It is added to every AI request that writes copy for that website: page builds, section redos, the AI editor and the copywriter.

## Redo one section

Not happy with one band of a generated page? **Redo** writes that section again in the page's own design, using its saved palette, fonts and style, and leaves every other section alone. An undo bar lets you go back.

## Add a page to a finished site

Ask for one more page in the same style as the rest of the site. It uses the home page's design profile and the site's style memo, so it matches without a new build.

## Images

- Generated pages write image placeholders as search terms, such as "bakery sourdough close-up", which are turned into real matching photos from Pexels, Unsplash or Openverse.
- Each generated page can get an original AI-made banner image.
- The **Add asset** dialog searches stock photos and generates images from a prompt (see [Stock photos and AI images](../stock-photos-and-image-generation)).
- Image alt text can be suggested by the AI from the picture itself.

## Language

A website has one language, chosen in the project wizard. Every AI path writes in it, and published pages declare it to browsers and search engines.
