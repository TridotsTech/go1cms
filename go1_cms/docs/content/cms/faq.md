# FAQ

## Is GO1CMS free?

The apps are open source and free to self-host. The hosted service has a free Starter plan and paid Medium and Premium plans.

## What is the difference between Starter and Medium?

Starter is one website as a project on a shared GO1CMS site. Medium is a site of your own with custom domains, five websites and a team. See [Plans and limits](/docs/plans-and-limits).

## Can I move from the hosted service to my own server?

Yes. A published project exports as JSON and files; import it into a self-hosted bench. Starter to Medium moves are done for you from the control panel.

## Do I need to know Frappe?

No. The builder, collections and forms need no code. Developers can go further with saved queries, scripts and the API.

## Which browsers does the builder support?

Current Chrome, Edge, Firefox and Safari on desktop. Published sites work on every modern browser, including phones.

## Where is my data hosted?

Hosted plans run on Frappe Cloud, by default in Mumbai, India. Premium can choose a region.

## How do I get help?

Open the docs first. Hosted customers can write from the control panel; self-hosters use GitHub issues and discussions.
