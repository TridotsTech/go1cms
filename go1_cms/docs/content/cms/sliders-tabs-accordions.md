# Sliders, tabs and accordions

## Slider

The **Slider / Carousel** element is a real carousel: each child of the slider is one slide, built with ordinary elements. Set its behaviour in the Content tab:

- autoplay, and how long each slide stays,
- previous and next arrows,
- dots that jump to a slide,
- looping back to the first slide at the end.

Slides are ordinary containers, so their size and spacing follow the styles you give them on each device.

A slider can also be a repeater's child list, so slides can come from data, such as products or testimonials.

## Tabs

**Tabs** shows one panel at a time with a row of tab buttons. Each panel is a container you design freely. Set which tab opens first.

## Accordion

**Accordion** stacks questions and answers that open on click. Choose whether several may be open at once. The **Toggle Accordion** event action opens or closes an item from any other button.

## Lightbox and gallery

**Image Gallery** shows a grid of images; clicking one opens it full screen with keyboard navigation. Any single image can open in the lightbox too.

## Other interactive elements

The Elements panel also has a stepper, a timeline, a progress bar, stats counters that can count up to their value, badges, tags, alerts and tooltips.
