# Introduction

GO1CMS is a visual website builder that runs on the Frappe framework. You design pages on a canvas, bind them to real data, and publish with one click. It is open source, and it is also offered as a hosted service with a free Starter plan.

## What you get

- **A canvas builder.** Drag sections and elements, zoom and pan like a design tool, and edit text in place. Every element has an inspector with layout, typography, spacing, borders, effects and events.
- **Responsive and stateful styles.** Desktop, tablet and phone breakpoints per element, plus hover, active and focus states and entrance animations.
- **A section and template library.** Hundreds of brand-neutral sections across more than thirty categories, plus whole-site templates for common industries. All of them are editable trees, not opaque blocks.
- **Content and data.** Collections (from DocTypes, saved queries or external APIs), repeaters with pagination and filters, forms that write to any DocType, and page variables and events without code.
- **Theme Studio.** Colour, type and spacing tokens that every page follows, per project.
- **Publishing.** Versioned publish with rollback, server-side rendering for fast first paint and SEO, per-project subdomains and custom domains.
- **AI and automation.** Generate a site from a brief, and drive the builder from Claude or any MCP client through the GO1CMS MCP server.

## Two ways to run it

| | Hosted (go1cms.site) | Self-hosted |
| --- | --- | --- |
| Setup | Create an account, pick a plan | `bench get-app` on your own bench |
| Hosting | Frappe Cloud, managed by us | Anywhere Frappe runs |
| Limits | Per plan (pages, storage, bandwidth, domains, members) | None |
| Updates | Automatic | You pull and migrate |
| Cost | Free Starter, paid Medium and Premium | Your infrastructure |

The hosted service and the open-source apps are the same code. The control panel that sells plans and provisions sites is a separate app that self-hosters never install.
