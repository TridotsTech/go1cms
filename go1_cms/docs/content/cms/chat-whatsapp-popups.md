# Live chat, WhatsApp and popups

Three plugins add a widget to every page of a website. Each is set per website in **Plugins**.

## Live chat

Supports Tawk.to, Crisp, Intercom and Tidio, or a custom script URL.

- **Widget / website ID** from the provider. The ID is checked for the provider you picked, so a wrong ID fails when you save, not silently on the live site.
- **Hide on these paths**, such as the checkout.
- **Show on** all devices, phones only or desktops only.
- **Wait for cookie consent** and **delay load** by a few seconds, so the chat never slows the first paint.

## WhatsApp button

A floating button that opens a WhatsApp chat with your number.

- The number is checked when you save, and the prefilled message is encoded for you.
- Choose the label, position (bottom or middle, left or right) and devices.
- A **greeting bubble** can appear after a delay.
- **Opening hours**: pick the open days and times. Outside them the button shows a message you write instead of opening a chat nobody will answer.

## Popups and announcement bar

- **Announcement bar** at the top or bottom, with text, a link, colours and a close button.
- **Popup** with a title, text, an image and a button, shown immediately, after a delay, after scrolling a percentage of the page, or when the visitor is about to leave.
- **Frequency**: once, once per visit, or every few days, remembered in the visitor's browser, so nobody sees it on every page.
