# Comments and client review

## Review comments on pages

Teammates and clients can leave comments pinned to a page while it is still a draft.

- In the builder, comment on the whole page, on one section or element, or on a point inside it.
- Reply in a thread and **resolve** when it is done; resolved threads can be reopened.
- Everyone already in a thread is emailed when someone replies.

## Review links for clients

Create a **review link** for a page. The client opens the page's draft from the link, with no account, and comments the same way. Give the link a label, an expiry date, or revoke it at any time.

## Share links

A **share link** is a view-only preview of a page for anyone with the address. Unlike a review link, it has no comments. Turn link sharing on or off per page; the shared view mirrors the canvas layout you had.

## Who is editing

When someone else has the same page open in the builder, their avatar shows in the top bar. The same person in two tabs shows as "you, in another tab". If two people save the same page, the second is asked whether to keep their version or take the other one, and the replaced version is kept in the page history.

## Blog comments

Visitor comments on blog posts are moderated in **Comments** (see [Blog and posts](../blog)).
