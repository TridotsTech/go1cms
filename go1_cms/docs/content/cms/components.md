# Components and reusable blocks

A component is a section or an element you build once and reuse on many pages. Change the component and every page that uses it can follow.

## Saving a component

Select a section, or any element inside one such as a card or a button row, and choose **Save as component**. Give it a name and a group. It appears in the **Components** tab of the left sidebar and in the Insert panel.

- A **section component** holds a whole band of a page.
- An **element component** holds anything smaller.

## Editing a component

Open a component from the Components tab. It opens on its own canvas in the same builder, with the same inspector, layers and preview. Save it like a page.

## Updating the pages that use it

After editing, **Sync** pushes the new version into the pages that use the component. Pages are updated in place, so their own content around the component is untouched.

## Components and the section library

A component is also listed in the [section library](../sections-and-templates), where you can preview it, tag it, choose which projects may use it, and insert it into a page as an independent copy. An independent copy no longer follows the component.

## Site header and footer

The header and footer have their own mechanism, shared by every page of a website: see [Header, footer and responsive header](../header-and-footer).
