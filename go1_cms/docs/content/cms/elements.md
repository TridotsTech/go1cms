# Elements

Elements are the building blocks on the canvas. Drag them from the insert panel or press **+** on a selected container.

## Structure

- **Container** groups children with flex or grid layout.
- **Section** is a full-width container that maps to one row of the page.
- **Slider** turns its children into slides with arrows, dots and autoplay.
- **Link** wraps children with a page, URL or anchor target.

## Text and media

- **Heading**, **Text** and **Rich text**, edited in place.
- **Image** with focal-point cropping, alt text and lazy loading.
- **Video** and **Embed** for players and third-party HTML.
- **Icon** from the built-in set or an uploaded SVG.

## Interactive

- **Button** with variants from the theme.
- **Input**, **Textarea**, **Select** and **Checkbox** are native form controls bound to page data.
- **Form** renders a Form Builder form and submits it to a DocType.
- **Filter** writes its value to the page URL so bound repeaters refetch.
- **Repeater** repeats its child for every row of a collection.
- **Web form** and **Webshop** elements arrive with plugins.

## Common settings

Every element has an id, a class list, visibility per device, a **Show when** condition bound to page data, entrance and loop animations, and events (click, hover, load) that run actions such as navigate, set a variable, call an API or run a script.
