# Plugins

Plugins add extra features to a website: for example a shop, live chat, WhatsApp, popups or cookie consent. You turn each one on for the websites that need it.

## How to open it

Choose **Plugins** in the **Apps** group of the nav rail.

## What you can do here

1. **Browse.** Search with "Search plugins…". A card marked **Needs setup** still needs something from you before it works.
2. **Open a plugin.** Click a card to see where it is **Active** (the projects it runs on).
3. **Turn it on for a website.** Under **Projects**, find the website and choose **Activate**. A plugin you activate never changes a website you did not choose.
4. **Change its settings.** Choose **Open settings** on a project where it runs, then fill in the **Settings**. Some plugins have none.
5. **Turn it off.** Switch it off on a project. The pages it created stay, but stop working until you activate it again.

> [!NOTE]
> If the list says "No plugins installed", none has been added to this site yet. Ask your administrator.
