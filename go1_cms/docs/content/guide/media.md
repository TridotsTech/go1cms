# Media

Media is the library of every image, video and file your websites use.

## How to open it

Choose **Media** in the **Content** group of the nav rail.

## What you can do here

1. **Upload.** Drop files onto the page ("Drop files to upload": images, videos, SVGs…).
2. **Find.** Search by name, use **Filters** and **Tags**, and switch between grid and list view.
3. **Organise.** Make a **New folder**, then use **Move to…** to file assets. **Rename** and delete folders from the folder options.
4. **Open an asset.** The detail panel has **Copy URL**, **Download**, **Edit photo** (crop, rotate or resize) and **Open in a new tab**.
5. **Add alt text.** Under **Properties**, describe the image for people who cannot see it, and add a **Caption**. It is used wherever the image appears without alt text of its own.
6. **Check where it is used.** **Used on** lists the pages, sections and logos using the file; **Refresh usage** updates it.
7. **Stock & AI.** Find stock photos or make images with AI.

> [!NOTE]
> Replacing or deleting a file used on pages can break those pages. Check **Used on** first. Deleting a file that is used asks you to confirm.
