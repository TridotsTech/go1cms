# AI Settings

AI Settings controls the AI that builds pages, writes copy and edits sections: which model it uses, and how much it may spend.

## How to open it

Choose **AI Settings** at the bottom of the nav rail.

## What you can do here

1. **Connect.** Under **Connection**, add your key. It then shows as configured, with **Connected**. **Change** replaces it and **Remove** deletes it.
2. **Choose the AI model.** Pick one from the list, search by name or provider, or **Show all models**. Some are marked **Free**.
3. **Add image keys.** Under **Images**, optional keys let the AI find or generate photos for the pages it builds.
4. **Set usage limits.** Set a **Daily budget per user (USD)**, **AI requests per user per hour**, and a **Daily budget for the whole site (USD)**. A whole-site build makes one or more requests per page. System Managers are exempt from the per-user limits.
5. **Check today's use.** **Today** lists how much each person has used.
6. **Advanced.** **Max Tokens**, creativity and **Request Timeout (seconds)**. The defaults work for most sites.

> [!NOTE]
> Raise **Max Tokens** if generations cut off early, and the timeout if a slower model gives up.
